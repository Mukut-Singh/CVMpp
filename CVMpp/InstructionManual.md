# CVMpp Quick Start Guide

## Prerequisites

Before you start, make sure you have:

* Windows PowerShell
* `g++` installed with C++17 support

*Note: If a prebuilt `cvm.exe` is already in the repository, you can skip the build step and run the samples directly.*

---

## Step 1: Open the Project

Fire up PowerShell and jump into your project directory:

```powershell
cd C:\Users\myste\myprojectsgithub\CVMpp

```

---

## Step 2: Build from Source

To compile the interpreter yourself, run this command:

```powershell
g++ -std=c++17 -I include src\main.cpp src\token.cpp src\scanner.cpp src\parser.cpp src\compiler.cpp src\vm.cpp -o cvm.exe

```

---

## Step 3: Run the Code

### Option A: Interactive Mode (REPL)

Want to test snippets on the fly? Launch the REPL:

```powershell
.\cvm.exe

```

**Example usage:**

```c
let x = 10;
print x;
x = x + 5;
print x;
exit

```

### Option B: Script Mode

To execute pre-written scripts, pass the file path directly to the executable:

```powershell
.\cvm.exe SampleTest\BasicMath.cvm
.\cvm.exe SampleTest\variables.cvm
.\cvm.exe SampleTest\booleans.cvm
.\cvm.exe SampleTest\IfElse.cvm
.\cvm.exe SampleTest\whileLoop.cvm
.\cvm.exe SampleTest\Calculator.cvm
.\cvm.exe SampleTest\TrueFalse.cvm

```

### Option C: Try the Input Demo

Run this script to test reading live user input from the console:

```powershell
.\cvm.exe SampleTest\InputPrint.cvm

```

*Simply type a value and press **Enter** when prompted.*

---

## What's Happening Under the Hood?

Whenever you run a script, the terminal will dump three distinct phases:

1. **The Abstract Syntax Tree (AST):** The structural map parsed from your source code.
2. **The Compiled Bytecode:** The low-level instructions (`OP_ADD`, `OP_PRINT`, etc.) generated by the compiler.
3. **The VM Execution:** The live output as the stack-based Virtual Machine processes those instructions.
